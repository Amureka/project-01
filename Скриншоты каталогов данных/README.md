**Видео с пользовательским флоу DataHub:** [DataHub 201: Impact Analysis](https://www.youtube.com/watch?v=BHG_kzpQ_aQ). В 03:13 ведущая открывает MongoDB и датасет pet profiles; в 03:42 показывает Impact Analysis, затем фильтрует зависимости по дашбордам (04:00–04:20) и выгружает список с владельцами (04:22–05:23). Видео поясняет, какие кадры нужны для полноценной галереи, но не является источником сохранённых изображений.

**Видео Power BI:** [What is a Lineage View in Microsoft Power BI?](https://www.youtube.com/watch?v=kET8hpd05M4&t=183s) (Power Tech Speck, 2025). На 03:03 показан общий граф, затем автор использует `Show lineage` у AdventureWorks Sales и показывает подсвеченную цепочку. Скриншоты в галерее — два полноэкранных примера из официальной инструкции Microsoft с одним объектом Account revenues; это не кадры из видео. В документации отображаются старые демонстрационные данные/даты, поэтому она подтверждает последовательность и состояния функции, но не самую новую визуальную тему Power BI.

Другие ранее загруженные изображения оставлены в папке как дополнительные материалы; интерактивная галерея использует только перечисленные выше файлы.
